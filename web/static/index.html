· 岸桥：按岸桥位置表中当前登记的作业船舶判断
· 场桥 / 堆高机：优先按 Conda 中该设备绑定的作业船舶判断
 未绑定时，回退取该设备近 N 分钟（当前取 15）内最近一条卸船作业指令对应的船舶
 由于回退依赖时间窗口，未绑定设备的显示会随时间和指令更新而变化
 装船设备必定存在绑定关系，因此装船场景下绑定表数据优先，无需回退到指令表
 以上数据来源可在前端配置
